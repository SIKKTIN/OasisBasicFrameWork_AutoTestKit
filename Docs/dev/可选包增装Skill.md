逐项阅读指令，核对以下部署情景的决策与范围：

| 情景 | 指令要求 |
| --- | --- |
| 已有框架增装任务包，带 UI、无示例 | 保留业务配置，仅接入正式包、UI、适配和所需索引 |
| 任务包仅逻辑 | 关闭 ui.enabled，跳过 uiOnly 文件、控件及 UI 行 |
| MCP 缺失或未连接目标 | 引导准备，继续本地只读检查，禁止将其列为部署成功 |
| 已有配置、同名资产或 UI 行冲突 | 给出具体合并方案，保留业务，不能覆盖清空 |
| 已安装且内容匹配、或部分接入 | 匹配跳过；部分接续，避免重复 Attach 与资产 |
| 基础不完整或依赖新增 | 列出差异与范围，不静默重装基础或添加未选包 |
| 老存档缺少新包字段 | 仅补本包数据，保留其他字段及存档版本，实际验收迁移 |
| 生成器扫描已有业务包 | 预览全目标，保留原清单与扩展，发现遗漏先修正 |
