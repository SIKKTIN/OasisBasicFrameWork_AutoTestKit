# 绿洲启元引擎文档导航

这里收录绿洲启元编辑器及 UGC 玩法开发相关文档，覆盖编辑器操作、Lua 脚本、玩法系统、UI、性能优化、商业化和发布流程等内容。

本文件负责“怎么找文档”，不替代完整的逐篇索引：

- [完整编号索引](000_索引.md)：按文档编号从 `001` 到 `259` 列出全部文章。
- [版本日志](版本日志/001_1.35%20Release%20Notes.md)：确认编辑器版本、功能变更和兼容性信息。
- `oasis_docs_sample.md`：编辑器主要窗口的内容示例，不是正式索引入口。

## 阅读与检索建议

- 先看分类入口，再用文章编号定位细节；需要完整清单时回到 [000_索引](000_索引.md)。
- 涉及编辑器操作时，优先阅读“新手入门”和“绿洲编辑器基础内容”；涉及运行时逻辑时，再进入“进阶内容”和“通用功能”。
- 涉及版本差异、上传或提审时，先查“版本日志”和“常见问题”，再阅读具体功能文档。
- 文档内的 API、截图和外部链接可能随平台版本变化；遇到行为不一致时，记录当前编辑器版本并结合对应版本日志核对。

在仓库中全文搜索关键词时，可在 `docs/` 目录执行：

```powershell
rg -n "关键词" . -g "*.md"
```
