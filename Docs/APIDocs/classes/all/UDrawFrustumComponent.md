Utility component for drawing a view frustum. Origin is at the component location, frustum points down position X axis.

## 属性

| 类型 | 名称 | 描述 |
|------|------|------|
| Color | **to** | draw the wireframe frustum. Angle of longest dimension of view shape. If the angle is 0 then an orthographic projection is used Ratio of horizontal size over vertical size. Distance from origin to start drawing the frustum. Distance from origin to stop drawing the frustum. UTexture *Texture optional |
