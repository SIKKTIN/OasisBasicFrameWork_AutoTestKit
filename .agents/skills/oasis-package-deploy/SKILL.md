# Oasis 可选包增装

只接入用户选择的包及已确认的必要依赖。已有框架、业务配置、数据和资源是保留对象；模板默认配置不能覆盖它们。用户仅要求计划或检查时保持只读。

## 定位工具与接入指南

从本 Skill 文件的文件系统真实路径定位工具仓库：先解析用户级目录联接，再从 `.agents/skills/oasis-package-deploy` 返回仓库根。目标工程另外确定，不能把工具仓库或旧 `setting.json` 当成目标。

检查 `Templates/*/manifest.json` 的 `optional`、`requires`、文件及生成声明。当前支持如下包；执行前读取选中包的 manifest、README 和对应指南，路径均相对于工具仓库。不要假设各 manifest 字段完全相同，或把新出现的目录当成已支持包。

| 包 | 模板目录 | 详细接入指南 | 默认行为 |
| --- | --- | --- | --- |
| GM | `Templates/framework-gm` | [GM](../oasis-project-deploy/references/gm-template.md) | 通用开发面板与控制器 RPC 适配 |
| AttributeSystem | `Templates/framework-attribute` | [属性](../oasis-project-deploy/references/attribute-template.md) | 空属性配置，保持编辑器数值，不强制满血 |
| SkillSystem | `Templates/framework-skill` | [技能](../oasis-project-deploy/references/skill-template.md) | 空技能配置，不携带技能资产 |
| TaskSystem | `Templates/framework-task` | [任务](../oasis-project-deploy/references/task-template.md) | 空任务配置，默认带基础 UI，可选仅逻辑；Examples 默认不安装 |

这些包当前都依赖 `framework-base`，彼此不作为默认安装前提。任务的正式奖励由项目实现 Validate / Query / Grant 及持久化去重；示例余额是模拟数据。安装任务包不等于已接入真实金币、物品或经验。

## 只读预检

1. **确定目标和选择。** 读取目标工程约定、相关实现与当前改动，明确绝对目录、`.ugcproj`、所选包、UI/示例选项及验收范围。明确请求优先；未选包保持不安装。缺少关键选择时先检查可独立确认的部分，只询问缺失项。
2. **核实 MCP。** 发现相关工具并实际读取编辑器 `ctx:`，核对工程、挂载根、PIE 状态及所选包需要的能力。工具出现、端口开放或握手成功不等于连接目标成功。缺失或失败时读取 [MCP 准备指南](../oasis-project-deploy/references/mcp-setup.md)，区分未安装、未配置、服务未启动、编辑器未连接、工程不匹配和能力缺失；证据不足写未确认。可继续本地检查，编辑器项保留待验证。环境改动依指南核对现有授权，不能编造安装来源或启动命令。
3. **检查基础兼容性。** 对照 [启动契约](../oasis-project-deploy/references/startup.md) 与选包实际实现，检查 LifeCycle/DataCore 就绪事件、实际 GameMode 绑定的 PC/Pawn 入口、包初始化与 Tick、退出清理。数据包还检查玩家属性组件的存档流程和实际 PC 的生成复制字段；带 UI 才检查 DT_UI_Config；有开发指令才检查对应跨端入口。按实际 API/生命周期判断，不能仅凭基础文件与模板哈希不同判定不兼容。
4. **核对增量与冲突。** 比较 manifest 文件哈希、包名、Meta、配置、适配器方法、数据键、UI 资产/行 ID 和待生成文件。确认 Lua 5.4 的有限时执行结果；GenKit 使用本次明确的 PROJECT_ROOT/SCRIPT_DIR，不修改工具 `setting.json`。读取现有生成配置与清单，预览全目标扫描结果，检查业务包遗漏、同名键和手写扩展。

基础缺失或不兼容时列出具体差异，转向 [基础框架部署](../oasis-project-deploy/SKILL.md) 评估；不能在增装过程中静默重装 Core、替换四个入口或重建属性组件。若需要新增依赖，先列出范围变化，不默认加入未选包。

按实际状态处理，而非一律重新安装：

- 文件、资产和接入均匹配：保留并跳过写入；已有可复用的验收证据需注明版本和范围，不能冒充本次运行结果。
- 仅部分接入：列出缺失环节，接续完成，不重复 Attach、监听、复制声明或 UI 行。
- 同名内容有业务修改：保留原内容并提出具体合并差异；可明确合并的按范围处理，无法确定用途的冲突先澄清。
- 配置、资产或数据含义冲突：明确解决方案或替代 ID；不能清空配置、删旧资源或迁入来源业务来绕过。

展示预检报告：目标与实际 MCP 上下文、包/版本/选项、基础兼容性、已安装状态、拟写文件/资产/入口/索引、冲突方案、外部备份位置、验收及尚缺信息。取得用户对具体报告的确认后执行；已有会话授权覆盖该报告时直接继续，不按步骤重复询问。仅计划时不写目标、不运行生成器写入、不启停 PIE。目标或范围有实质变化时更新报告并核对授权。

## 接入已确认的增量

1. **备份。** 在目标工程外保存将变更的脚本、配置、生成文件和资产，记录原路径、版本及实际差异。保留未提交改动。编辑器资产按保存状态备份；有运行实例时先确认是否需结束当前会话，不能直接覆盖正在使用的资源。
2. **复制与合并。** 按 manifest 校验正式 payload，只新增缺失文件，合并已批准的业务差异。空默认表不覆盖已有任务、技能、属性或奖励提供者。TaskSystem 仅逻辑时设置 `ui.enabled=false`，跳过 uiOnly 文件、控件和 UI 行；示例只有明确选择才单独安装。
3. **连接实际入口。** 解析真实 GameMode/PC/Pawn 绑定，按包指南加入所需适配和生命周期，保留现有 RPC 白名单、OnRep、EndPlay、GM 等适配。每个 Attach 只接入一次；不靠同名文件猜运行入口，不在通用 Core 中增加包专用分支。
4. **增量处理 UI。** 依指南使用实际 helper，先 inspect，后单资产 PRV 写入、编译、保存并读回。复用兼容的 DT_UI_Config 六字段结构，仅合并选包行，保留全部其他行；行冲突确定新 ID 后同步配置和定义。已有匹配资产保留；结构冲突不能盲目重建或强制覆盖。表/组件细节按需读取 [表指南](../oasis-project-deploy/references/editor-tables.md) 与 [组件指南](../oasis-project-deploy/references/editor-components.md)。
5. **处理新增玩家数据。** 检查新增键在新玩家及已有存档缺少此键时的初始化、迁移、保存和复制。只补本包数据，保留其他键、原有版本及未识别存档。不能把旧玩家当新玩家重置整个存档；读档错误或未知状态不能当“不存在”。按包实际状态接口检查迁移和待保存状态。
6. **生成并核对。** 按 manifest 的 generateIndexes 和实际接入需要对完整目标运行 GenKit。保留已有包、数据键、业务表声明、开发指令、套件及手写扩展；不能从选包目录或空种子生成整项目清单来替换原结果。新增数据键须进入 Meta、常量、分类事件与实际 PC 复制声明。预览和写回后比较，发现旧内容丢失先修正，不继续启动。

失败或断连后，先检查磁盘与编辑器实际已保存状态，再从未完成环节接续；不反复创建资产，不自动回滚覆盖用户期间新增的改动。

## 运行验收与收尾

有新入口、索引、初始化或资产变更时，从最终文件新启动 PIE。使用本次 session 的真实 client/DS 日志，检查基础仍正常、玩家数据就绪、所选包状态和实际 PC 复制；不要用热更后的旧闭包或历史 TempleTest 报告判定新部署通过。

- GM：面板、按钮、服务端 RPC 返回及权限拒绝；测试结论依据最终报告，派发成功不算执行通过。
- AttributeSystem：状态就绪，默认空配置出生/重生不改血量和移动值；有已选属性规则再验证其同步。
- SkillSystem：数据和状态就绪；空配置无实例添加，有实际技能才验证引擎实例、启停及恢复。
- TaskSystem：空配置正常；有 UI 验证入口、空态、滚动及关闭。已有任务或选示例时验证接取、服务端进度、复制、领奖和重复请求；真实奖励/回执恢复仅在有相应提供者并实际覆盖时判定。

新增数据包还需覆盖旧存档缺键且其他数据保留。新玩家初始化、已有玩家迁移、同局读回、跨对局持久化分别记录；编辑器不支持的发布环境验证明确留待实际环境。没有套件是 no-tests，离线检查或 Lua 请求成功不能代替实机验收。

完成后停止本次 PIE 并关闭本次测试客户端，释放内存；移除临时探针、恢复临时索引，保留正式配置及用户原有测试。报告已装包/选项、保留与合并内容、备份位置和验证证据。必需接入或运行验收未完成时，明确写“增装未完成”及接续点；全部一致无需修改时如实报告“已安装，无需变更”。不执行上传发布。
